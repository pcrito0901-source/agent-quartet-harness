# VideoHub

## 概要
ユーザーが動画をアップロードし、他のユーザーが視聴できるシンプルな動画共有プラットフォーム。
YouTube のような大規模配信ではなく、社内やコミュニティ内での動画共有を想定する。

## ターゲットユーザー
- 動画を共有したい発信者（勉強会の録画、チュートリアル、社内報）
- それを探して見る視聴者

## 機能一覧

| 優先度 | 機能 |
|---|---|
| 高 | 動画のアップロード（タイトル・説明付き） |
| 高 | 動画一覧の表示 |
| 高 | 動画の再生 |
| 中 | タイトル・説明での検索 |
| 中 | 再生回数のカウント |
| 低 | コメント |
| 低 | ユーザー認証・マイページ |

## 技術スタック推奨
- フレームワーク: Next.js (App Router)
- 言語: TypeScript
- 動画ストレージ: ローカルファイルシステム（Sprint 1）→ 将来的にオブジェクトストレージ

## 確認事項

Planner が推測で埋めた前提です。違う場合は計画を作り直します。

- **前提1: 認証は Sprint 1 では扱わない**（根拠: 「アップロードして視聴できる」が要望の中心で、認証への言及が無いため。まず動画のコア体験を成立させる）
- **前提2: 動画は数十MB程度、同時視聴者は少数**（根拠: 「サービス」の規模指定が無いため。トランスコードやCDNは対象外とする）
- **前提3: 公開範囲の制御は無し（アップロードされた動画は全員が見られる）**（根拠: 権限の要望が無いため）
