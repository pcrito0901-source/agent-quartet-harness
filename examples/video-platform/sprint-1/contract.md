# Sprint 1: 動画のアップロードと再生

## 実装する機能
- 動画アップロード: ファイル選択・タイトル・説明を入力して保存する
- 動画一覧: アップロード済みの動画をサムネイル付きで一覧表示する
- 動画再生: 一覧から選んだ動画を再生する

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

| ID | 条件 | 検証方法 |
|----|------|----------|
| C0-1 | プロジェクトが初期化され、開発サーバーが単一コマンドで起動する | `docs/runbook.md` のコマンドで起動し、ベースURLが 200 を返す |
| C0-2 | `docs/runbook.md` に起動コマンド・ベースURL・テストデータ投入手順が正確に記載されている | 記載どおりに実行して再現する |
| C0-3 | Playwright が導入され `npm run e2e` で実行できる | `npm run e2e` が終了コード 0 で完了する |
| C1 | トップページに動画一覧が表示される | `/` を開き、動画カードが1件以上描画される |
| C2 | 動画が0件のとき、空状態メッセージが表示される | データを空にして `/` を開き、「まだ動画がありません」が見える |
| C3 | `/upload` でファイル・タイトル・説明を入力して送信できる | フォームに入力して送信し、`/` にリダイレクトされる |
| C4 | アップロードした動画が一覧の先頭に表示される | C3 実行後、一覧の1件目が入力したタイトルになっている |
| C5 | タイトル未入力で送信するとバリデーションエラーが表示される | タイトル空で送信し、エラーメッセージが見える |
| C6 | 一覧の動画をクリックすると再生ページに遷移する | カードをクリックし、URLが `/watch/:id` になる |
| C7 | 再生ページで video 要素が再生可能な状態になる | `video` 要素の `readyState` が 1 以上になる |
| C8 | 再生ページに戻るリンクがあり、一覧に戻れる | 戻るリンクをクリックし、URLが `/` になる |
| C9 | 100MBを超えるファイルは拒否され、理由が表示される | 大きいファイルを選択し、エラーメッセージが見える |
