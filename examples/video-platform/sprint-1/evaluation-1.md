## Phase 4: デザイン評価

| 基準 | スコア | 該当アンカー | 根拠 |
|------|--------|--------------|------|
| デザインの質 | 7/10 | 7-8「階層は明確。1〜2箇所に詰めの甘さ」 | 見出し階層は3段階明確。ただしカード内のメタ情報の余白が 12px と 16px で混在（`VideoCard.module.css:22, 31`） |
| オリジナリティ | 7/10 | 7-8「定型から外れた工夫が2箇所以上」 | スロップ兆候0件。先頭カードのスパン、再生ページの暗色反転の2点が定型から外れている |
| クラフト | **4/10** | 3-4「状態表現がほぼ無い。またはフォーカスリングを消して代替を用意していない」 | `app/globals.css:41` で `*:focus { outline: none }` を指定し、代替のフォーカスリングが無い。**ルーブリックの即時減点トリガーに該当** |
| 機能性 | **5/10** | 4-6「いずれかの幅で崩れる」 | 375px で再生ページの `<video>` が親幅を超え、横スクロールが発生 |
| **加重総合** | **6.25** | | 7×0.35 + 7×0.35 + 4×0.15 + 5×0.15 |

**閾値未達: クラフト（4 < 5）、機能性（5 < 7）。** 加重総合は 6.0 を超えているが、
個別閾値を満たしていないため不合格。

### Designer への修正指示（Generator の修正後に実行）
1. `app/globals.css:41` の `outline: none` を削除するか、`box-shadow: var(--focus-ring)` を必ず併記する（トークンに `--focus-ring` が定義済み）
2. `app/watch/[id]/page.tsx` の `<video>` に `max-width: 100%; height: auto` を当てて 375px の横スクロールを解消する
