## フェーズの値

`未着手` → `計画済み` → `実装済み` → `デザイン済み`（または `デザイン省略`）→ `回帰済み` → `評価中` → `合格` / `不合格`

- `デザイン省略`: 見た目が変わらない回。**省いた理由を下の履歴に書く**（`CLAUDE.md` の「早める4つの手」の3）
- `回帰済み`: オーケストレーターが評価の前にフル回帰を1回だけ回し、赤を一度に洗い出した（同じく1）

## リトライ

Evaluator が不合格を出すたびに +1。**3 に達したらループを止めてユーザーに判断を仰ぐ**
（契約が実現不能、またはエージェントが同じ失敗を繰り返している可能性が高い）。
