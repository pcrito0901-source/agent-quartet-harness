# リリース確認チェックリスト

`/release-check`が参照する、人間とAIの共通チェックリスト。自動検証できない項目を合格扱いにしない。

## 共通

- [ ] 全スプリントが合格
- [ ] 型チェック、lint、ユニットテスト、E2Eが成功
- [ ] 未コミット変更の内容を説明できる
- [ ] 本番用の環境変数と秘密がリポジトリに含まれていない
- [ ] エラー監視、問い合わせ先、ロールバック方法が決まっている

## Expo / React Native

- [ ] Windows上のExpo Webだけでなく、配布用ビルドを作成した
- [ ] iPhone実機またはTestFlightで主要導線を確認した
- [ ] 小さい画面と大きい画面でレイアウトを確認した
- [ ] オフライン、通信失敗、権限拒否を確認した
- [ ] カメラ、通知、写真、位置情報、マイク等の利用目的文を確認した
- [ ] Appleログイン、ディープリンク、バックグラウンド動作を確認した
- [ ] 課金がある場合、購入・復元・解約後の状態を確認した

## App Store

- [ ] Bundle ID、バージョン、ビルド番号が正しい
- [ ] アプリアイコン、起動画面、スクリーンショットを用意した
- [ ] 名前、サブタイトル、説明文、キーワードを用意した
- [ ] サポートURLとプライバシーポリシーURLが有効
- [ ] App Privacy、Privacy Manifest、年齢区分を確認した
- [ ] 暗号化申告と輸出コンプライアンスを確認した
- [ ] 審査用メモと、必要な場合は審査アカウントを用意した
- [ ] TestFlightで最終ビルドを確認した

## 承認境界

ビルドのアップロード、TestFlight配布、審査提出、公開は外部状態を変更する。実行直前に対象アプリ、バージョン、配布先を示し、人間の明示承認を得る。
