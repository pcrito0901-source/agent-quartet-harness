# 見本の目録

> **この表に載り、承認の欄に日付がある見本が正本**である。実装と評価は、これに合わせる。
> 載っていない画像は、方向づけの参考画像として扱う（そのまま再現しない）。
>
> - 見本を作るのは `@agent-designer`（`/design` の見本モード）。**承認の欄はオーケストレーターが書く**（ユーザーが承認したとき）
> - 直したら版を1つ上げ、承認の欄を空に戻す（もう一度承認を取る）。
>   ただし `/polish` でユーザーが決めた直しは、その日付を承認として書いてよい
> - 承認の後に見本を変えるのは**決定**（`docs/product-direction.md` の `V-n`）。変わる画面ID を名指す
